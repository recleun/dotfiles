# dotfiles

This is my dotfiles, you are free to use whatever you need.

## Usage

```bash
    ./rotfiles.sh install <module>            # To install a module
    ./rotfiles.sh uninstall <module>          # To uninstall a module
    ./rotfiles.sh install bundle <bundle>     # To install a bundle (A group of modules)
    ./rotfiles.sh uninstall bundle <bundle>   # To uninstall a bundle
    ./rotfiles.sh list                        # To list all available modules and bundles
    ./rotfiles.sh list modules                # To list all available modules
    ./rotfiles.sh list bundles                # To list all available bundles
    ./rotfiles.sh status                      # To check which modules are installed
    ./rotfiles.sh status <module>             # To check the status of a specific module
```
